# Автопроверка без Mongo и без Telegram

`loader.py` здесь — заглушка: коллекции в памяти, вместо бота — фейковая сессия,
которая записывает вызовы Bot API. Позволяет прогнать админку целиком, не трогая
боевую базу.

```bash
cd bot_refactor/selfcheck
cp -r ../core ../admin .        # модули должны лежать рядом с заглушкой loader.py
python3 check.py                # настройки, тарифы, CRUD, лимит длины callback_data
python3 flow.py                 # сценарий админки через реальный Dispatcher aiogram
```

`check.py` уже поймал две ошибки при разработке: точки в ключах настроек Mongo
трактовал как вложенные пути, и обмен порядка в списке превращался в
присваивание, если словарь успевал обновиться между двумя update_one.
