# RS VPN Bot

Каркас бота на aiogram 3 + Mongo с единой админкой: цены, проценты, тексты и
включение/выключение функций меняются из Telegram без деплоя.

Структура и правила — в [ARCHITECTURE.md](ARCHITECTURE.md).

Перенос со старого бота и настройка — в [SETUP.md](SETUP.md).
Переезд на сервер под pm2 — в [DEPLOY.md](DEPLOY.md).
Что изменилось между версиями архива — в [CHANGES.md](CHANGES.md).

## Запуск в PyCharm

1. `File → Open` → выбрать папку **rsvpn-bot** (именно её, а не родительскую:
   иначе импорты `app.*` не найдутся).
2. `Settings → Project → Python Interpreter → Add → Virtualenv` (Python 3.11+).
3. В терминале PyCharm: `pip install -e ".[dev]"`.
4. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`, `ADMIN_IDS`,
   `MONGO_URI`. Файл читается автоматически (`app/core/config.py`), плагин
   EnvFile не нужен.
5. Готовые конфигурации запуска лежат в `.run/`: **bot**, **api**, **tests** —
   появятся в списке справа вверху сами.

## Запуск из терминала

```bash
cp .env.example .env      # заполнить API_TOKEN, ADMIN_IDS, TOKEN_DB
make install              # или: pip install -r requirements-dev.txt
make check                # проверить, что всё заполнено и база доступна
make migrate              # индексы + дефолтные тарифы
make run                  # бот
make api                  # вебхуки платежей (отдельный процесс)
```

Windows: те же команды через `.\make.ps1 <задача>` — `make` там не установлен.

Или целиком:

```bash
docker compose up -d
```

## Команды администратора

Не в меню и не в списке команд Telegram: их не должно быть видно обычному
пользователю.

| Команда | Что делает |
|---|---|
| `/admin` | панель: статистика, настройки, тарифы, рассылка |
| `/ban 123 причина` | закрыть бота; подписка продолжает работать |
| `/hardban 123 причина` | то же плюс отключение подписок в панели |
| `/unban 123` | снять любую блокировку |
| `/deluser 123` | удалить пользователя целиком — для тестовых аккаунтов |
| `/diag` | что из фонового работает: продление, напоминания, кампании |

`/deluser` стирает документ, платежи, подарки, использованные промокоды и
подписки в панели, поэтому спрашивает подтверждение и показывает, что
именно удалит. После него твинк проходит регистрацию как новый человек.
Администратора удалить нельзя.

## Вебхуки панели Remnawave

Напоминания об истечении подписки приходят событиями от панели, а не опросом
базы раз в 15 минут. Настройка на стороне панели (`/opt/remnawave/.env`):

```bash
WEBHOOK_ENABLED=true
WEBHOOK_URL=https://webhook.rsvps.tech/remnawave/webhook
WEBHOOK_SECRET_HEADER=<длинная случайная строка>

EXPIRATION_NOTIFICATIONS_ENABLED=true
EXPIRATION_NOTIFICATIONS=-72,-24,-12,-6,-3,-1,24   # часы: минус — до, плюс — после
```

Тот же секрет кладётся в `.env` бота как `REMNAWAVE_WEBHOOK_SECRET`.

Бот принимает `user.expiration` (часы лежат в `meta.expiration`), `user.expired`
и старые имена событий до версии 2.8.0. Какие пороги реально отправлять —
переключается в `/admin → ⏰ Напоминания об истечении`, тексты правятся там же
в разделе «Тексты бота».

Что важно знать:

* панель ретраит недоставленные вебхуки, поэтому каждое напоминание
  «застолблено» в `vpn.notified.<ключ>` — повтор не даст второго сообщения;
* флаги сбрасываются при продлении, иначе в следующем цикле напоминаний
  не будет;
* события по ByPass-подписке распознаются и пропускаются: это отдельный
  пользователь в панели;
* эндпоинт всегда отвечает 200 — иначе одна наша ошибка превращается
  в бесконечную очередь ретраев со стороны панели;
* списание с баланса осталось в планировщике: вебхук может не дойти,
  а деньги должны списаться в любом случае.

## Админка

`/admin` в боте:

* **⚙️ Настройки** — 49 параметров в 7 разделах: цены, бонусы, лимиты,
  платёжные методы, кампании, ссылки, тексты. Булевы значения переключаются
  одной кнопкой, числовые проверяются по границам, каждая правка пишется в
  журнал аудита.
* **💰 Тарифы** — цена, длительность, подарки, порядок кнопок, вкл/выкл.
* **🧩 Быстрые ответы**, **🎁 Промокоды**, **📝 Тексты бота** — тот же
  универсальный CRUD.

Новая настройка — строка в `app/settings/schema.py`. Новый список —
объект `EntityAdmin` в `app/admin/entities.py`. Хендлеры писать не нужно.
